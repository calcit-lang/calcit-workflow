# Upgrade Calcit 0.13.77 / 升级 Calcit 0.13.77

## English

- Upgrade the template toolchain and `@calcit/procs` baseline from Calcit 0.13.32 to exact 0.13.77 without changing the template package version.
- Replace the archived external `calcit-test` development module with the built-in `calcit.test` API and keep both native and JavaScript test entries active.
- Preserve the `calcit.std` runtime example dependency and the template's once/watch workflow.
- Track this migration through calcit-lang/calcit#716 and umbrella calcit-lang/calcit#657.

Validation with exact Calcit 0.13.77 source revision `5915ccf3`:

- repository-source `caps --ci`, `caps tree`, and `caps why calcit-lang/calcit.std`; the preserved `calcit.std@main` request resolves to `c3f91a1c`
- canonical Snapshot SHA-256 stability after a second formatter pass
- default/test entry check-only and dynamic-method warning gates
- check-types, weak-types, and deprecated analysis with no new migration-specific failure
- native test entry execution and JavaScript test codegen/Node execution
- immutable Yarn install with only the intended `@calcit/procs 0.13.77` lockfile change

`caps --strict --ci` rejects the repository's pre-existing mutable `calcit.std@main` reference. This upgrade preserves that documented provider reference and uses the repository's existing `caps --ci` gate; calcit-lang/calcit#658 owns the provider upgrade/release boundary.
